Saved characters

Pick up where you left off — loads profile, EDF, and master face.

Architecture: the two models are given disjoint prompts. The thinking model receives the narrative core — dossier, persona, history, metrics — and the image model receives only the render doctrine plus the identity ledger. The renderer never sees the story; metrics reach it translated into photographic direction instead.

Media Ingestion

Upload reference photos and short video clips. The thinking model builds your Entity Definition File (EDF).

Media constraints

  • Videos: max 3 files — 30 seconds each — 25 MB each (forensic only — not kept as image refs)
  • Photos: max 20 — 80 MB total pool — wardrobe / face / environment refs (saved with the character)
  • Formats: JPG, PNG, WEBP, MP4, WEBM
